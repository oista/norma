# Naming — арка имён

Канон третьего продукта арки — **Clavis** (лат. *clavis* — ключ).

| Имя | Роль в лоре | Продукт / пакет |
|-----|-------------|-----------------|
| **Clavis** | Замковый камень | Онтологический движок |
| **PRODATA** | Каменоломня + тёска | Платформа provenance / portal |
| **ENTAN** | Каменщик с отвесом | Enterprise Analyst |
| **Norma** | Наугольник (мера) | Shared-репозиторий, не продукт |
| **forma** | Лекало | `norma-forma` — дизайн-токены |
| **libella** | Отвес | `norma-libella` — агентский рантайм |
| **canalis** | Канал / водовод | `norma-canalis` — контракт коннекторов к внешним системам |

Алиас: ранний черновик имени был **Cavis** — канон теперь **Clavis**.

Направление зависимостей: продукты → Norma. Norma не импортирует продукты.
