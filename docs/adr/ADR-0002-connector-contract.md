# ADR-0002: connector-contract

**Статус:** Accepted
**Дата:** 2026-08-11
**Related:** [ADR-0001](ADR-0001-seam-contract.md), [naming.md](../naming.md), Clavis ADR-0007 / ADR-0015, PRODATA ADR-0019

## Контекст

Харвестеры Clavis (CIR → OCR) и физический ингест PRODATA (GitLab → PG/Neo4j, далее DWH-каталог / EAM / Clinkr) нуждаются в доступе к внешним системам: Oracle/Greenplum, REST, Jira, SPARQL и т.д. Если контракт коннекторов живёт внутри любого продукта, второй продукт вынужден либо импортировать код продукта (запрещено [ADR-0001](ADR-0001-seam-contract.md) п.1), либо дублировать транспорт.

Норма — единственное легальное место для домен-агностичного инструментария (прецедент: `norma-forma`, `norma-libella`). Нужен пакет того же класса для доступа к системам.

## Решение

1. **Пакет `norma-canalis`** (*canalis* — канал/водовод) в `packages/norma-canalis`: контракт доступа к внешним системам.
2. **Контракт (минимум):** `connect()`, `capabilities()`, типизированные read-примитивы, paging, retry, разрешение секретов, audit-hook. Конкретный Protocol/ABC фиксируется при выходе пакета; этот ADR задаёт дом и границы.
3. **Библиотека, не сервис.** «Сервис коннекторов, к которому ходят все» воспроизвёл бы рантайм-шину, отклонённую в ADR-0001. Продукты импортируют `norma-canalis` и вызывают драйверы in-process.
4. **Драйверы — optional extras** (`norma-canalis[oracle,jira,sparql,…]`). Ядро без тяжёлых зависимостей; продукт выбирает extras.
5. **Вне Norma остаются:**
   - корпоративная специфика (`v_dg_*` как модель каталога, объектная модель EAM/Clinkr) — у producer-продукта;
   - MCP / HTTP tool-поверхности — у продукта с RBAC и аудитом (`platform_mcp`, `clavis_api`);
   - harvest / CIR — у Clavis (ADR-0001 п.3).
6. **Purity:** пакет собирается и тестируется при нуле продуктов; тесты на фейках/фикстурах, без корп-эндпоинтов в CI (`scripts/check_norma_purity.py`).
7. **Шов в реестре:** строка `canalis-connect` в [seam-registry.md](../seam-registry.md) заводится **вместе с выходом пакета** (правило 1 реестра — не описывать швы «на будущее»).

## Последствия

+ Оба продукта легально делят транспорт без product→product импорта.
+ Имя вписывается в арку (`forma` / `libella` / `canalis`).
+ Драйверы не раздувают зависимости потребителей без нужды.
- Четвёртый пакет Norma; нужен релизный ритуал и extras-матрица.
- Корпоративные адаптеры поверх canalis всё равно живут в продуктах — граница требует дисциплины.

## Альтернативы

- Коннекторы внутри Clavis (`clavis_connect`): отклонён — PRODATA не может импортировать Clavis.
- Коннекторы внутри PRODATA: отклонён — Clavis не может импортировать PRODATA; ломает boundary.
- Отдельный репозиторий `moex-connectors` вне арки: отклонён — дублирует роль Norma без закона швов и purity-гейта.
- MCP-сервис на каждую систему как первичная абстракция: отклонён — смешивает транспорт с RBAC; батч-харвест и agent-lookup имеют разную нагрузку; Norma не владеет политикой доступа продуктов.
