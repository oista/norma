# Config contract (экосистема)

Краткая выжимка env-префиксов. Полная копия жила в ENTAN/PRODATA design-notes; канон поднимается сюда.

| Префикс                         | Владелец                                      |
|---------------------------------|-----------------------------------------------|
| `EDA_` / legacy без префикса    | ENTAN (agent)                                 |
| `PRODATA_`                      | PRODATA Platform                              |
| `ONTOLOGY_`                     | Clavis (ontology engine)                      |
| `CAVIS_`                        | **legacy alias** for Clavis (do not use new)  |
| `NORMA_`                        | Shared (опционально: путь к tokens)           |

Связанные: ENTAN `docs/design-notes/2026-07-26-config-contract.md`, PRODATA `docs/architecture/config-contract.md`.
